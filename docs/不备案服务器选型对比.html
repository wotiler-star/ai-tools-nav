一、为什么是香港节点（不是日 / 美 / 新加坡）

  • 免 ICP 备案：香港 / 境外服务器 + 任意域名（含 .cc / .com）均无需备案，域名 A 记录解析即时生效。
  • 到大陆延迟最低：电信 / 联通 / 移动平均 25–50ms；日 / 美 / 新节点普遍 100ms+，国内访客打开明显慢。
  • 能跑 Docker 全套：你的项目是 MySQL + Redis + Spring Boot + Next.js + Nginx 的 docker-compose 全栈，必须是一台完整 Linux 虚拟机，共享主机 / Serverless 不合适。

三、技术适配：2核4G 是全栈项目的性价比地板

五个容器同跑一台机：MySQL + Redis + Spring Boot 后端 + Next.js 前端 + Nginx。

  • 2核4G（推荐）：内存充裕，运行稳定，镜像构建也不易炸。
  • 2核2G 不推荐：腾讯香港 2C2G 可压到 ¥24/月 / ¥99/年，但五个容器同跑 2G 必频繁 swap 甚至 OOM，docker build 大概率失败。仅适合纯静态 / 极简后端。

日 / 美 / 新加坡节点

六、注意事项

① 备案误解：只有「大陆服务器」才需 ICP 备案；香港 / 境外服务器 + 任意域名（含 .cc / .com）均免备案。
② 续费价：上述为 2026 活动首年价，续费通常恢复官网原价；长期使用建议一次性买 2–3 年锁价，或关注「同价续费」专区。
③ 带宽规则：腾讯香港基础款带宽 / 流量有限（特惠款已含 2048GB / 月，导航站足够）；若图片流量大，阿里云「200M 不限流量」更省心。

1 项目概述

本项目旨在构建一个 AI 工具导航与社区网站，全面构建toolly AI 导航站（https://www.toolly.cc/）的核心功能、视觉体验与全栈技术架构。该站本身就是toolly团队出品的 AI 工具聚合 + AI 社区平台，与本项目定位完全吻合，属于同域对标构建。

核心价值

🧭

导航聚合

聚合海量 AI 工具资源（ChatGPT、Midjourney、Stable Diffusion 等），按分类清晰组织，用户一键直达。

👥

社区互动

内置学习交流社区，用户可发布短文/文章、点赞评论、打卡学习，形成活跃的 AI 探索社区。

🤖

AI 助手

集成 AI 智能助手，帮助用户快速找到所需工具、总结工具特点、推荐适配方案。

📊

用户体系

完整的用户注册登录、等级成长、VIP 会员体系，激励用户持续参与。

构建说明：本项目在页面布局、交互逻辑、功能架构与全栈技术栈上全面对标 www.toolly.cc。该站前端为 React 18 + Next.js 14（App Router），后端为 Spring Boot + MyBatis-Plus（域名 api.toolly.cc），两者共用同一套技术底座，本项目做到逐技术对齐、可验证。

3 技术架构与选型

本项目 全站架构和技术栈与toolly AI 导航站（www.toolly.cc）完全一致，前端使用 React 18 + Next.js 14（App Router 模式）服务端渲染，后端使用 Spring Boot + MyBatis-Plus（API 域名 api.toolly.cc），配合 Redis 多级缓存、Elasticsearch 搜索引擎、Sa-Token 权限控制等企业级技术，通过 Nginx 反向代理 + 腾讯云 CloudBase Run 托管统一对外服务。

验证方式：本次技术栈全部基于 www.toolly.cc 实测——前端下载其生产环境 49 个 JS chunk 文件（共 2.32 MB）做全量代码分析；后端直接抓包 api.toolly.cc 的 API 响应头与返回数据。每一项技术均标注实测证据与出现次数，非主观臆测、非依据其他项目推断。

4.2 后端功能模块

🔐 认证授权服务

  • 用户注册/登录：邮箱+验证码注册，密码加密存储
  • Sa-Token 认证：基于 Sa-Token 实现登录认证、Token 管理，支持同端登录冲突检测
  • 多方式登录：基于 Sa-Token 实现手机号+短信验证码、微信扫码（wx_mp）、票据登录（ticket，第三方授权回调）、模拟登录（mock，演示用）；支持账号绑定（account/bind）与同端登录冲突检测
  • 权限控制：基于 Sa-Token 的 RBAC 模型（普通用户 / VIP / 管理员）
  • 接口限流：基于 Sentinel 进行接口限流、热点参数限流、熔断降级

📁 导航数据服务

  • 分类管理：大类 → 子分类的树形结构，支持增删改查
  • 工具管理：AI 工具的 CRUD，含图标上传、标签关联
  • 搜索服务：基于 Elasticsearch 实现分词搜索，支持高亮、排序、聚合
  • 浏览统计：异步记录工具浏览量，Redis + Caffeine 多级缓存计数 + 定时同步 DB
  • 推荐排序：按浏览量 + 收藏量 + 评分综合排序，HotKey 探测自动缓存热点工具

📝 社区内容服务

  • 帖子/文章 CRUD：短文（essay）和长文（post）两种类型
  • 互动系统：点赞、评论、分享的增删查，基于 Redisson 分布式锁防重复操作
  • 标签管理：标签自动提取与关联，支持话题聚合页
  • 内容审核：敏感词过滤（DFA 算法）+ 人工审核队列
  • 信息流排序：按时间倒序 + 热度加权综合排序

👤 用户成长服务

  • 等级系统：经验值累积，5 级体系，不同等级解锁不同权益

10.3 Nginx 配置要点

server {
    listen 443 ssl;
    server_name your-domain.com;

    ssl_certificate     /etc/nginx/ssl/cert.pem;
    ssl_certificate_key /etc/nginx/ssl/key.pem;

    # 前端：代理到 Next.js 服务（支持 SSR）
    location / {
        proxy_pass http://frontend:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # Next.js 静态资源（_next 目录）
    location /_next/ {
        proxy_pass http://frontend:3000;
        proxy_cache_valid 200 1d;
    }

    # API 反向代理
    location /api/ {
        proxy_pass http://backend:8080/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # Gzip 压缩
    gzip on;
    gzip_types text/plain text/css application/json application/javascript;
}

# HTTP 重定向 HTTPS
server {
    listen 80;
    server_name your-domain.com;
    return 301 https://$host$request_uri;
}

10.4 CI/CD 流程

代码提交 → 自动构建 → 部署
  ├── 前端: npm install → next build → docker build → 推送镜像 → 服务器拉取并重启（next start 生产模式）
  ├── 后端: mvn package → docker build → 推送镜像 → 服务器拉取并重启
  └── 通知: 钉钉/飞书 Webhook 推送部署结果

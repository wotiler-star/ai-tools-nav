> 配套主文档：《首页与导航栏设计方案.md》第八节。
> 本文把「交流社区」从设计落到**可实现的 API + 前端 + 数据模型 + 治理**，参考鱼皮导航（ai.codefather.cn）「AI 交流社区 / 热门文章 / 提示词」的 UGC + 编辑混合形态。

---

## 一、社区定位

把站点从「工具目录」升级为「**工具 + 人 + 内容**」的留存引擎：
- **用完即走 → 天天来逛**：动态、问答、提示词建立关注关系与创作惯性。
- **UGC 内容池**：评测/教程/提示词反哺 SEO 长尾与首页内容，降低编辑成本。
- **信任背书**：真实用户心得比官方简介转化更高。

---

## 二、信息架构与页面

```

/user/[id]         用户主页：动态 / 收藏 / 提示词 / 关注
```

## 三、数据模型（Prisma，并入主 schema）

```prisma
model User {
  id        String   @id @default(cuid())
  name      String
  avatar    String?

  role      String   @default("user") // user | editor | admin
  posts     Post[]
  comments  Comment[]
  likes     Like[]
  followers Follow[] @relation("followers")
  following Follow[] @relation("following")

model Post {
  id        String   @id @default(cuid())
  authorId  String
  author    User     @relation(fields: [authorId], references: [id])
  type      String            // article | question | prompt | review
  title     String
  content   String            // Markdown
  tags      String   @default("")
  toolId    String?           // 关联 AI 工具
  views     Int      @default(0)
  likes     Int      @default(0)
  favorites Int      @default(0)
  comments  Int      @default(0)
  solved    Boolean  @default(false)
  isFeatured Boolean  @default(false)
  status    String   @default("published") // pending | published | hidden
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt
  @@index([type])
  @@index([createdAt])
}

model Comment {
  id       String   @id @default(cuid())
  postId   String
  post     Post     @relation(fields: [postId], references: [id])
  authorId String
  author   User     @relation(fields: [authorId], references: [id])
  parentId String?
  content  String
  likes    Int      @default(0)
  createdAt DateTime @default(now())

}

model Like {
  id     String @id @default(cuid())

model Follow {
```

## 四、API 设计（Route Handlers）

### 4.1 动态流 `app/api/community/route.ts`
```ts
import { NextResponse } from "next/server";
import { prisma } from "@/lib/db";

export async function GET(req: Request) {
  const { searchParams } = new URL(req.url);
  const tab = searchParams.get("tab") ?? "recommend"; // recommend|latest|hot|qa|featured
  const where: any = { status: "published" };
  if (tab === "qa") where.type = "question";
  if (tab === "featured") where.isFeatured = true;

  let orderBy: any = { createdAt: "desc" };
  if (tab === "hot") orderBy = { likes: "desc" };        // 生产可改 (likes*2+favorites+views*0.1)
  if (tab === "recommend") where.OR = [{ isFeatured: true }]; // 简化：加精优先

  const posts = await prisma.post.findMany({
    where, orderBy, take: 20,
    include: { author: { select: { name: true, avatar: true } },
               _count: { select: { comments: true } } },
  });
  return NextResponse.json(posts);
}
```

### 4.2 发帖（鉴权 + 校验 + 敏感词）`app/api/community/route.ts` POST
```ts
export async function POST(req: Request) {
  const session = await getServerSession(authOptions);
  if (!session) return NextResponse.json({ error: "Unauthorized" }, { status: 401 });

  const body = await req.json();
  const parsed = PostSchema.safeParse(body); // Zod：title/content/type/tags
  if (!parsed.success) return NextResponse.json(parsed.error, { status: 400 });

  if (containsBadWord(parsed.data.content)) // 敏感词过滤
    return NextResponse.json({ error: "内容含违规词" }, { status: 422 });

  const role = (await prisma.user.findUnique({ where: { id: session.user.id } }))?.role;
  const post = await prisma.post.create({
    data: { ...parsed.data, authorId: session.user.id,
             status: role === "user" ? "pending" : "published" }, // 新用户首帖待审
  });
  return NextResponse.json(post, { status: 201 });
}
```

### 4.3 互动（点赞/收藏/评论）`app/api/community/[id]/interact/route.ts`
```ts
export async function POST(req: Request, { params }: { params: { id: string } }) {
  const session = await getServerSession(authOptions);
  if (!session) return NextResponse.json({ error: "Unauthorized" }, { status: 401 });
  const { kind } = await req.json(); // like | favorite
  await prisma.like.upsert({
    where: { userId_postId_kind: { userId: session.user.id, postId: params.id, kind } },
    create: { userId: session.user.id, postId: params.id, kind },
    update: {},
  });
  // 同步 Post.likes/favorites 计数 + 作者 points +1
  return NextResponse.json({ ok: true });
}
```

> 评论、关注、提示词复制同理，全部走「服务端鉴权 + Zod + 计数同步」三件套。

## 六、互动与激励

- **点赞 / 收藏 / 评论 / 转发**：服务端同步计数，`Post.likes/favorites/comments` 实时更新。
- **关注**：`Follow` 关系，用户主页聚合「他的动态 / 收藏 / 提示词」。
- **积分等级**：发帖 +5、被赞 +1、提示词被复制 +1（`User.points`）；等级解锁「发外链」「创建合集」等权益（P2）。
- **社区榜单** `/community/rank`：贡献榜（按 points）、热门作者（按获赞），周更，强回访。

---

## 七、内容治理（P0，必须有）

1. **敏感词过滤**：发布时服务端校验，命中则拒发或转待审。
2. **新用户首帖待审**（`status: pending`），编辑后台审核后发布。
3. **举报 + 编辑操作**：每帖/评可举报；后台可置顶/加精/隐藏/删。
4. **XSS 防护**：Markdown 渲染用 `react-markdown` + `rehype-sanitize`；所有用户输入转义。
5. **限流**：发帖/评论按用户 ID 限频（如 1 条/10s），防 spam。

---

## 八、性能与 SEO

- 社区首页列表走 **ISR**（`revalidate=60`）；详情页 `generateMetadata` 输出标题+描述+OG。
- 动态流**首屏服务端渲染**前 20 条，下拉/翻页走客户端 `/api/community`。
- 提示词、问答都是**长尾词金矿**，每帖独立 URL 被收录。
- 用户主页 `noindex`（避免低质 UGC 拖累整站权重）。
